# BTC Trading Bot

A real-time BTC trading simulation bot with a glassmorphic dashboard interface, dynamic confluence guards, order book pressure weighting, and daily macro-technical XGBoost models.

## Local Development

1. Install requirements:
   ```bash
   pip install -r requirements.txt
   ```

2. Train the models:
   ```bash
   python train.py
   ```

3. Run the bot:
   ```bash
   python main.py
   ```
