System Overview & Pipeline Architecture Core System

The BTC Trading Bot is an institutional-grade automated quantitative trading platform. It features multi-timeframe ML model ensembles (5m, 15m, 30m, 1h, 2h, 4h, 6h), Triple-Barrier labeling, Purged K-Fold Cross-Validation, Bayesian dual-governance release gates, continuous CUSUM/PSI drift detection, portfolio risk controls, and a full-featured real-time dashboard.

Pipeline: Market Data (Bybit WS/REST) -> Feature Engineering -> ML Ensembles (XGB/LGB/Cat) -> Isotonic Calibration -> Confluence Meta-Gates -> Portfolio Risk & Sizing -> Exchange Execution -> Trailing Engine -> MLOps Telemetry
main.py Core Execution Engine

Purpose: Main system orchestrator and execution entry point. Houses the main asynchronous event loop, candle aggregation threads, multi-timeframe prediction polling, order execution, and live trailing stop monitoring.

Key Formulas & Strategies
  • Dynamic Kelly Criterion Sizing: Sizes position leverage based on calibrated model win rate $p$, loss rate $q=1-p$, and reward-to-risk ratio $b$:
    f^* = \frac{p \cdot b - q}{b}, \quad \text{Applied Fractional Kelly: } f_{\text{actual}} = f^* \cdot \text{Kelly\_Fraction} \cdot \text{Covariance\_Mult}
  • ATR-Based Dynamic Stop-Loss & Take-Profit:
    \text{SL} = \text{Entry} \mp (1.44 \cdot \text{ATR}_{14}), \quad \text{TP} = \text{Entry} \pm (3.25 \cdot \text{ATR}_{14})
  • Multi-Timeframe Boundary Alignment: Triggers 4H strategy evaluation strictly when current_utc_hour % 4 == 0.

portfolio_risk.py Portfolio Risk Engine

Purpose: Institutional portfolio risk management, VaR/CVaR calculation, Volatility Parity sizing, correlation exposure scaling, and Portfolio Heat telemetry.

Key Formulas
  • Correlation Penalty Factor: Scales down total position size when multiple correlated assets trigger simultaneously:
    \text{Correlation\_Multiplier} = \frac{1}{\sqrt{1 + \rho_{\text{avg}} (N_{\text{corr}} - 1)}}
  • Portfolio Heat %: Total unhedged risk exposure relative to account equity:
    \text{Portfolio\_Heat\_Pct} = \frac{\sum_i (\text{Position\_Size}_i \cdot |\text{Entry}_i - \text{SL}_i| / \text{Entry}_i)}{\text{Total\_Equity}} \times 100\%
